# مغامرة الغذاء الصحي وغير الصحي

لعبة تعليمية تفاعلية باللغة العربية للأطفال للتعرّف على الغذاء الصحي وغير الصحي، مع أوضاع لعب وأسئلة وسلة تصنيف.

## التشغيل

افتح `index.html` في المتصفح. الواجهة تتكيّف مع شاشات الجوال والكمبيوتر.

## النشر

الموقع ثابت ولا يحتاج إلى خادم. يمكن نشره عبر GitHub Pages من فرع `main` ومجلد الجذر.
